# Paper

This folder contains the philosophy paper for the Automate the Intake project.

- **automate_intake_preserve_thinking_paper.pdf**
  23-page paper covering the Automate, Amplify, Preserve framework, context architecture as the core skill in AI-assisted work, the AI bubble and physical infrastructure limits, the disconnection crisis, and a personal philosophy for working with AI without losing what makes human judgment irreplaceable. Written from inside the first recruiting cycle meaningfully affected by AI at scale. Research, reasoning, opinions, and voice are the author's own.
